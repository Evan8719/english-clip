## 建议比较的动作

- 手机上打开原版现有词条，点卡片翻面，再在对照稿点一张短卡和一张长句卡。
- 向下滚动多屏，试顶部搜索、最近/字母排序和单双列切换；观察是否挡住正文。
- 打开「＋记录」，检查键盘弹出时保存按钮、来源详情、语境、个人理解和造句能否方便触达。
- 看词头粗细、边框层次、卡片间距，以及单手操作时是否容易误触。

手机尺寸的设计稿已经导入为独立的 `mobile` 草稿，并校验服务端保存的 HTML 与本地完全一致；两个公开地址返回 200。当前电脑的浏览器控制服务未能启动，所以尚未取得这次草稿的实际手机视口截图，也未执行手机触控验收。用户在真实手机上的反馈是这一步的判断依据。

此前素材库、语音对话和 AI 相关控件仍是标注的原型演示。正式应用目前仅接入第一批真实听说素材入口，完整新版界面未部署。
