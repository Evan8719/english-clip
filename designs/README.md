## 本轮内容

紧凑个人本子、详情查看、快速记录、翻卡复习、跟读状态演示、带着收藏表达练对话，以及设置示例。搜索、筛选、临时记录和对话示例仅操作浏览器内存；刷新后回到虚构示例数据。

实际语音播放、录音、转写和 AI 服务均未接入。原型不请求麦克风权限，不调用正式后端，不读取实际用户词条。依赖在线字体、Tailwind 和图标资源，因此这份设计 HTML 不是最终离线应用。
