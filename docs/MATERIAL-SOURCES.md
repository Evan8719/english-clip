# 素材来源与私人课程导入

用户要求免费、非 B 站的《走遍美国》学习材料。课程元数据来自 [Learn Real English 的课程索引](https://www.learnrealeng.com/p/family-album-usa-family-album-u.html)，26 个视频来源 ID 保存在 `public/courses/family-album.json`，保留逐集来源链接。备选 [LovelyLanguage 索引](https://www.lovelylanguage.ru/en-videolessons/family-album-usa/35-about) 提供逐幕 PDF 入口。

本轮将已核实公开可播放的 26 集视频存入用户 NAS 私人素材库，并在电脑本地生成文稿和时间轴，供 App 内训练。素材必须登录访问，视频和全文不进入 GitHub 或公开静态资源。此记录不授予再次分发的权利，也不宣称视频在任何网络、地区永久可用。

有声书可用现有音频播放器导入 MP3/M4A，按章节保留文件和书名，保存播放位置；同名 TXT/SRT/VTT 自动配对，配套 EPUB 进入阅读器。没有时间轴时通过本机转写生成逐句定位字幕。
