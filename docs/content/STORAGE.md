# 存储分层与恢复

- 程序：版本化 release，仅前端、服务程序、校验清单。
- 学习数据：data/store.json、data/media/index.json 与本机私有配置/密钥；小包备份排除 data/media/files、data/library。不得公开或提交 Git。
- 人可读资料：library/视频、音频、电子书/系列/自然语言标题；原始文件与 data/media/files 的 ID 路径是同盘硬链接，不额外复制媒体。字幕与逐词 JSON 为可再生侧文件。
- 兼容 ID 路径继续服务原有签名播放地址。可读目录由 nas/catalog-library.mjs 整理，更新 libraryPath 和目录 CSV；不会重建素材 ID 或清空笔记。重名加短 ID，已有文件绝不覆盖，路径越界/符号链接目录拒绝。

整理需停写并备份，使用 EC_DATA_DIR、EC_LIBRARY_DIR、EC_PID_FILE 和 --offline。新上传和转写完成后也更新相应可读资料。手工改名后，完整整理通过同一设备/inode 识别现有文件。此功能以同盘硬链接为前提，跨盘不能退回偷偷复制原件。

日常发布备份元数据包与原件快照分别记录。快照必须在停写期间冻结元数据；如使用硬链接，应复制所有可能原地写入的 JSON、密钥和轮转文件，只有不可覆盖的媒体原件保持硬链接。启动服务后才可压缩已冻结的元数据。

恢复时同时需要元数据与其对应原件。旧程序回退保留当前数据及 ID 原件，不用旧元数据覆盖发布后的新笔记。资料侧文件可由索引重建。独立磁盘/外部备份按用户自己的备份策略管理，本轮不删除旧整包或配置额外定时任务。
