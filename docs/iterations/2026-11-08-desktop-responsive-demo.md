## 明确的规则

- 全局设置：手机主页面与桌面右上角固定保留齿轮入口；皮肤放入设置的外观分组，不用调色盘图标替代设置。导入、搜索、历史各自保留语义，不占用或冒充设置入口。
- 缩略图管理：节目或书籍的「更多」中进入更换封面；支持原封面、用户上传及默认文字封面等候选行为。配置不改变素材 ID、原件、词条引用、笔记或进度。没有声称封面上传后台已实现。
- 一套数据、按屏幕组织界面：手机重内容和拇指触达，电脑重多列浏览与稳定工作区。桌面不用手机底栏；窄屏不强塞侧栏。

## 桌面素材库

保留左侧主导航，主区上方为听力/阅读/课程等切换。阅读区呈多列封面书架，列数随实际宽度适配；展示标题、作者、参考等级与已知进度。书架中继续使用现有 Alice 插画封面，并保留其他封面的文字设计能力。没有插画时不能把同一图片错配到所有书籍。

封面上的更多菜单是整理入口；更换封面不占据日常读书主界面。继续阅读为小型位置入口，不堆统计卡片；默认保留当前筛选与书架位置。新增缩略图应生成合适尺寸并缓存，不把原图塞入大 JSON 或在列表中下载全尺寸图。

## 桌面阅读

代码检查：现有 BookReader 有章节导航、StoryCover、阅读字号、暖纸/明亮/夜间、手动选词、记录与开口复述、沉浸阅读和位置恢复。现有 CSS 为目录 + 正文两列，正文有限宽。用户认可这些能力，后续不因手机改版擅自替换或删除。

正文维持舒适限宽与衬线英文阅读，不随整个大屏横向拉长。左侧保留目录和小封面，顶部明确返回书架；Aa 控制字号和阅读外观，与全局设置区分。默认读正文时不自动选择或弹出句子；手动选词后才出现查词、记一句、开口复述。Demo 中的右侧释义仅在选词时显示并可关闭，不是阅读时永久强占一列。沉浸模式可隐藏外围工具，退出后恢复原位置。

## 适配与验收要求

- 大屏书架至少验证常见桌面宽度、多行长标题、缺图及慢网络；断点由内容宽度决定，不仅以手机操作系统判断。
- 阅读验证窄窗、常规笔记本与大屏，正文不横向溢出，不因工具展开反复跳动；目录/笔记位置与阅读位置分别保存。
- 手机主页面、桌面素材页与阅读页都要检查设置可达；设置面板、封面菜单的键盘/屏幕阅读器和关闭返回行为另行验收。
- 当前只是响应式视觉方案，不能把图当作已经部署、安装 APK/IPA 或完成正式账号/真机验收。保持 Demo 确认后实施的规则。
