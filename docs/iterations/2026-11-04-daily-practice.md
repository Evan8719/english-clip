# 每日练习：从英文理解到个人表达

目标：使用本人已同步词条、原句、当前素材片段和近期每日练习反馈，选择短任务并进入 AI 对话。中文作为可展开的辅助，不禁止中文、不以固定“理解率”作为门槛，不宣称英文和中文各有单一逻辑。

入口置于开口练的“每日练习”；保留跟读一句和自由对话。等级 A1–C2 是用户可调的练习参考，不是假装正式测评；可选 5/10/20/30 分钟与生活场景。练习依据显示在页面，支持选一本书/音视频或自动按进度选择。

路线：先理解一小段 → 听一句并跟读 → 用自己的英文复述 → AI 场景对话 → 选择难度感受并保存一句反思。每天可短可长，无连续天数、打卡压力、提醒、会员。

AI 请求只取本账号少量表达、选中资料的短片段和近期练习摘要；不传整库/整本、不处理个人外链收藏。书籍取当前章节附近段落，音视频取当前播放位置附近字幕，引用保留素材 ID、位置与时间，不让模型编造出处。英英释义由 AI 简化生成并明确标注，中文按需展开。

[参考：Nation 的词汇覆盖与理解研究](https://doi.org/10.26686/wgtn.12552221.v1)；[British Council 的口语练习建议](https://englishonline.britishcouncil.org/blog/articles/8-practical-ways-to-practise-speaking-english/)。词汇覆盖与主观大意理解率不能混为一个百分比。


本地验证：类型/Vite 构建通过，lint 仅 3 个原有警告；独立每日 API 测试通过，包括按位置选原文、生疏词优先、个人外链排除、账号隔离、并发生成防重复、生成失败不损历史、对话重启后恢复、难度反馈进入下一次请求。手机浏览器使用真实隔离后端，仅模拟外部 AI；生成、英英释义、跟读返回、复述与对话保存、难度调整、历史/原文回跳、重载、离线草稿与联网重试通过。AI 回复期间编辑反思不会被返回结果覆盖。NAS 正式发布另见 release 记录；不能把模拟 AI 验收当真实模型生成。
