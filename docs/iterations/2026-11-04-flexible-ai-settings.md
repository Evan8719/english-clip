# 可配置 AI 服务设置

用户报告 Gemini 保存后无提示，并要求避免写死。根因：后端只接受旧 AIza 前缀且长度最多 300；新版授权密钥不兼容。前端反馈又放在下方云同步区，请求没有超时。

新增独立 AI 设置表单，接口地址、模型、回复方式均可编辑，预设可恢复；密钥视为不透明凭据，不凭旧前缀判断有效性。保存、调用测试、启用分开，局部反馈及 12 秒超时，失败保留输入，状态可重新读取。模型默认选项可省略提供方专用思考参数。

自定义地址必须是公开 HTTPS；DNS 查到私网即拒绝，实际 HTTPS 连接使用已验证的解析地址，不跟随重定向；密钥加密并绑定保存地址，更改地址需明确输入新密钥。已有旧加密格式可读。

验证：600 多字符的合成授权密钥可保存、加密、不回显，模型/地址可修改且重启保留；无密钥测试阻止、地址更换保护、参数与流式协议、内网地址和 DNS 过滤通过。手机浏览器验证保存、模型修改、启用、局部可见错误、12 秒超时解除等待、输入保留和状态读取。连接测试 UI 使用合成提供方，不冒充真实 Gemini 成功。

官方迁移依据：[Google API 密钥说明](https://aistudio.google.com/docs/api-key)。
