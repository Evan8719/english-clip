# 全局皮肤与闯关练习

用户明确要求将三套全局皮肤和小游戏纳入本次网页发布，安装包等稳定后再做。本次发布授权覆盖此前已确认的素材封面、手机与桌面布局，以及分类、标签、轻量进度候选；不代表后续可不经视觉确认直接重做 UI。

## 实现

- 设置内主动选择暖纸、清爽、夜读，当前设备保存；主页面、词卡、导航、表单、练习面板共用色彩变量。阅读默认跟随全局外观，既有明确阅读背景偏好保留。
- 复习保留自由翻卡，新增闯关练习。最多 5 个不同的个人词句；释义、原句和听音题以已有记录为依据。不确定释义不用于词义选择，选项不足降为回想自评。
- 题目快照、当前答案反馈和完成状态保存于当前账号的本机 IndexedDB；刷新后可续答，完成后可重练未记住的。新一轮替换当前轮，不提供完整关卡历史或跨设备同步。
- 熟悉程度仍由用户在翻卡中标记，不以一次答对自动修改。无连续打卡、体力、付费、提醒。无在线出题依赖，无发音评分。
- 安装包未制作。

## 验证

- TypeScript 与 Vite 构建通过；lint 无错误，保留原有 3 个未使用变量警告。
- `scripts/test-review-game.mjs`：唯一词句、选项、稀疏记录回退、不确定释义排除、不修改熟悉程度通过。
- Windows Edge 独立测试账号与数据：外观切换及刷新保存、5 题、答案反馈断点、完成与错题重练、离线切换恢复、单词音标规则、390×844 无横向溢出通过。
- 原素材流程回归：桌面书架、更换封面、阅读手动选句及沉浸设置、手机两列封面和筛选面板、节目页面通过。
- 夜读手机截图采用合成测试词句，已人工检查。
- NAS 发布及备份、线上验收结果另写入 `docs/releases/`。不以本地浏览器测试代替线上账号验收。
