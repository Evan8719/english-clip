# 素材体系与复习小游戏

状态：分层浏览、节目归属与用途编辑已完成本地候选，详见 [分类实施记录](2026-11-08-material-system-implementation.md)。小游戏仍是后续需求。用户要求先完善，暂不发布 NAS。此前候选版的用途推断筛选不等于本方案。

## 已核对的原目录

本机原资料保留三组：01_Books_电子书、02_Podcasts_播客、03_Listening_With_Transcript_带文稿听力。电子书下分 A1_入门、B1_中级、C1_高阶；播客下分 A2_慢速讲解、A2_生活实用、B1_短篇观点、B1_新闻叙事、B1_叙事逻辑、B2_访谈。完整私人目录和文件清单留在 work/，不进入公开源码。

原目录提供了类别、参考等级、学习用途，文件名中有节目与单集。导入不能丢掉这些信息，再让用户从一堆散文件重新找。旧 inventory 的电子书损坏标记已过时，用户已修复，不能据此丢弃素材。

## 信息各司其职

| 维度 | 示例 | 管理规则 |
| --- | --- | --- |
| 主库 | 听力、阅读、课程、精选视频、我的收集 | 每份一个主要入口；不按 mp3/mp4 文件格式决定课程归属 |
| 子类 | 播客、带文稿听力；小说、非虚构、短文 | 可编辑的内容类别；不确定时待整理，不凭书名杜撰 |
| 节目 / 课程 / 系列 | Life Kit、走遍美国、某读物系列 | 有稳定 ID 的集合，包含简介、封面、默认用途；改名不改关联 |
| 条目 | 某单集、课时、一本书、一篇短文 | 连接字幕、原件、练习、笔记、进度，沿用素材 ID |
| 学习用途标签 | 慢速讲解、生活实用、叙事逻辑、短篇观点、新闻叙事、长访谈 | 多选；节目设置默认，单集可增删；便于跨节目筛选 |
| 主题标签 | 饮食、职场、健康、旅行 | 按内容标注，多选，可自定义；不与用途塞在无差别标签池 |
| 参考等级 | A1–C2、待评估 | 单独字段，保留来源依据与人工调整；原著所在 A1 目录不代表正式分级读物 |
| 学习状态 | 未开始、进行中、已完成 | 根据真实用户操作生成，不以自动播放结束冒充掌握 |

词条的个人自定义标签继续作用于 Entry.tags；素材用途、主题各自管理和筛选，可在记录时展示出处信息，但不悄悄把所有素材标签灌入词条个人标签。

六个播客的节目默认用途：ESLPod→慢速讲解，Life Kit→生活实用，Planet Money→叙事逻辑，The Indicator→短篇观点，The Daily→新闻叙事，How I Built This→长访谈。同一节目可以多用途；新节目不应被硬编码规则限制。

示例：听力 / 播客 / Life Kit / 单集；用途「生活实用」，等级「A2」，主题「健康」。走遍美国只在课程主入口按 26 课浏览，不把视频文件散到普通听力首页；搜索结果可以跨库显示，同时标明归属路径。音频与视频原件、字幕均是条目附件，不另算一节课。

## 页面与导入

素材首页显示主库与最近学习；进入听力后先选播客 / 带文稿听力，以节目封面、标题、真实集数为单位，进入节目才展开单集。用途标签可跨节目筛选，点 Life Kit 也可单独看该节目。课程先显示课程，不默认铺开课时。阅读以书架和内容类别呈现，等级是筛选。顶部显示路径和明确返回，保留所在分组、分页、排序及滚动位置。

导入流程：选择文件/目录→读取原目录并匹配既有节目→预览主库、子类、节目、单集序号、参考等级、用途、字幕配对→用户可批量改归属→写入。同名节目要复用稳定 ID；不确定归属进待整理，不能静默误判。支持以后新增节目、课程及自定义用途。节目默认用途采用继承关系，单集 override 保存为显式覆盖，能区分“继承默认”和“我自己修改”。

## 数据与渐进迁移

建议独立 taxonomy.json 保存主库/子类/系列/用途及主题词表；每条素材保存 libraryId、categoryId、collectionId、sequence，以及用途继承覆盖、主题 ID、原目录来源记录。等级沿用 level / levelBasis；文件路径和标题不作为关联键。词条、书签、练习、原件仍沿用已有素材 ID。

按用户后续纠正：明确的旧资料直接自动归类，无逐项确认步骤。实现先只读验证归类结果；未知归属才待整理，需修正时用户可编辑。NAS 发布仍遵守整体备份与验收流程。迁移要有 schemaVersion、可重复运行与覆盖检测，不改已有手动分类。素材目录 CSV 同步增加归属字段，原件不搬动、不复制。节目改名或删除只改组织关系；删除集合默认移入待整理，不删除素材、笔记和词条。

验收：现有六个播客按真实原件计算集数；字幕文件不计单集；课程不散列；新增一集能归入既有节目；用途可跨节目筛选且能修正；手动等级、笔记、引用、进度和字节指纹全部保留；空系列与待整理可操作；手机层级往返不丢位置。

## 复习小游戏的下一步范围

用户希望类似多邻国的游戏闯关感。保留自由翻卡，在复习中另设「闯关练习」。每轮只需 5–8 个来自个人词句的小任务，可中途退出再继续，无连续打卡、体力限制、付费或强制提醒。

初版依次考虑：词义辨认、原句填空、听音选词、开口复述。用已有可信释义和原句生成题；缺释义/缺语音时换可用题型或跳过，不造假选项。词义多解时先展示语境；不把合理的同义回答误判。反馈简短说明原因，答错可重试，再出现以帮助学习。完成页显示本轮表达和建议复习项，不冒充 CEFR 或发音测评。

关卡进度、题目快照与版本、尝试和完成情况单独保存，不直接把答对一次标成「能用了」；熟悉程度仍由用户确认。离线优先使用本地可用题，AI 出题为可选扩展，不把复习绑在在线模型上。录音评分与跨设备关卡同步需另行验证。第一版不承诺这些题型和同步都已实现。

实施顺序：完成轻量进度候选→确认本分类数据模型并生成既有资料迁移预览→分层浏览与导入归属→复习闯关初版→统一手机验收后再讨论发布。
