# 素材分类实施候选

基线 3a45157，用户要求继续实现分层浏览，并明确已知旧资料直接归类、不增加逐项确认。保持暂不发布；正式 NAS 仍为 release-20261104-5e5c809-mobile-studio。

## 实际行为

- 首页显示听力、阅读、课程、精选视频、我的收集主库，进入节目/系列后才显示单集、课时、书籍。原硬编码走遍美国入口和散课时列表已替换为实际分组及真实数量。搜索可跨主库查找，标明类别及系列。
- 已知旧资料直接自动归类，不写正文或搬原件；只有无法识别时待整理。分类与素材 ID 独立，课程按 courseId 归组，六个播客以明确节目名匹配，带文稿听力与电子书保留独立类别。
- taxonomy.json v1 按账号保存 collections 和 placements。派生旧分组使用稳定 ID；新建使用 UUID，改名保留 ID 及旧名称别名。以后新文件能匹配旧节目名。新建同类别同名分组拒绝重复。
- 用途是节目默认多标签，单集可继承或覆盖（包括显式留空），主题为独立标签；等级继续沿用原字段。可修改类别、节目名、默认用途，逐条修正归属和单集序号；外部个人链接与精选视频不能互相混入，书籍不能归入听力。
- 批量文件与目录导入预览会识别节目（含别名）、书籍、带稿听力、走遍美国和原目录等级。只在同目录匹配同名 TXT/SRT/VTT；保留相对 importPath。归属可自动处理，也可选择已有分组；不强制额外确认。正文损坏提示仍需处理，不静默导入失败文件。
- 路径、搜索、分类、等级、用途、分页、排序按账号保存在本次浏览器会话；回素材页或重载可恢复。本机缓存保存列表和分组，离线继续浏览；分类编辑需联网。手机筛选默认收起，优先展示内容。
- 节目/课程默认用途与单集覆盖不改变个人词条标签，不改素材 ID、原件、文稿、练习、笔记和进度。

## 验证和边界

TypeScript/Vite、差异检查通过；lint 仅三个原有警告。隔离分类测试：自动解析不落盘、稳定 ID 改名、默认继承与显式空覆盖、账户隔离、重启恢复、重复分组拒绝、移动归属不改原索引/笔记/进度通过。原素材、轻量进度、每日练习 API 回归通过。

隔离手机浏览器：主库→节目→单集、课程整组显示、用途筛选、单集用途/主题编辑、改名关联、会话恢复、旧名匹配新导入、缓存离线浏览通过，无横向溢出。继续学习在新层级下的离线进度、冲突选择和返回正确章节回归通过。导入用合成文件；目录选择与真实手机文件选择器未做实机验收，不以浏览器模拟代替。正式账号 UI 未自动登录验收。

本轮不包含批量整理、合并/删除分组、AI 自动主题、闯关小游戏；电子书先按资料类别与等级整理，未凭书名强行判断所有文学体裁。API 编辑操作尚无乐观并发版本控制，未来多端同时改同一分组需补充冲突提示。

发布前应将 material-taxonomy.mjs 与上一轮 media-progress.mjs 纳入程序清单，将 taxonomy.json / progress.json 及备份纳入一致元数据备份；核对旧版回退兼容。当前没有部署包切换、没有正式数据迁移，也没有完成正式回退演练。
