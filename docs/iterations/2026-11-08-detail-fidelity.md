# 界面细节还原与六项修正预览

用户指出发布版没有跟上确认过的图片细节，要求完成后与 Demo 对照比较。本轮仅核对来源、制作独立可交互预览并保存验收要求；未修改 `src/`、NAS 后端、正式素材和线上部署。

参考：全局 UI 方案 B、首页三皮肤图和已发布版本 `7532d3a` 对应的浏览器截图。预览示例使用 curious、one step at a time、notice，均为合成词句，不写入本子。

## 已找到的原因

- HomeView 保留了旧的词句/素材/词典导航、介绍、记录按钮、完整分类横条以及词句列表说明，叠加后第一张卡的位置远低于设计稿。
- EntryCard 仍将听发音、造句、编辑、删除常驻在卡片底部，元信息串成长行；没有把来源封面和标签组织成设计稿的紧凑来源行。
- 旧 `DESIGN.md` 约定英文 Georgia，图片中的首页词头是粗体无衬线。上一轮没有在实施前解决这个视觉依据冲突。后续经确认后修订词卡排版，书籍正文继续保留适合阅读的衬线字。
- index.css 和 studio.css 都保留多轮外观覆盖；配色修改不等于组件结构还原。需在批准后的实施中统一相关样式来源，避免继续在末尾追加补丁作为主要办法。
- 原有 ELLLO 是 MaterialsView 底部独立折叠区域，没有进入 MaterialBrowser 的节目分类。返回入口也分别由阅读、外链、原生听力和练习各自呈现，缺少统一页面规则。

## 用户六项反馈与预览

| 问题 | 修正标准 | 预览验证 |
| --- | --- | --- |
| 底部字小且细 | 标签 14px、650 字重；图标约 22px；点击区域至少 44px；当前项只变图标与文字色 | 已测量本子、素材和详情底栏 |
| 白方块素材菜单突兀 | 节目、书籍、课程、精选视频、个人收集及单集统一横向三个圆点；不常驻白方块；44px 点击区域与可见小图标区分 | 素材与单集使用同一个三点菜单原型 |
| 返回混乱 | 详情和子页固定左上返回；下面用细分隔线和简短路径说明位置；返回恢复原列表、筛选、滚动或播放位置 | 演示素材→ELLLO→单集→开口复述→单集→ELLLO→素材→本子 |
| 同时两个设置入口 | 页面右上仅一个全局齿轮；素材三点只管理素材，阅读 Aa 只调阅读；不同容器不得重复渲染全局齿轮 | 预览单页全局设置计数为 1；真实 App 尚待逐路由排查 |
| ELLLO 难发现 | 主库听力 / 内容类型短篇对话 / 节目 ELLLO / 单集；主题筛选与节目不是一层混合标签 | 8 段真实目录在预览中归入三个主题，节目直接出现在听力首页 |
| 首页缺少设计稿感觉 | 去掉重复视觉层级；单列独立卡面、粗体无衬线词头、已有可靠音标、右上发音、来源缩略图与标签；文字工具移入更多或详情 | 实际 HTML 渲染并排图，正面单词卡约 139px、短语约 111px；长句须自然增高 |

ELLLO 的预览主题来自现有目录标题：日常生活（Driving、Weather、Recipe），兴趣爱好（Camera、Reading、Music），出行旅行（Favorite Place、Weekend Get-away）。等级沿用现有 A2 参考，不是重新评测。正式整合应复用原稳定 ID、音频、文稿和练习；无需复制音频或把它们当新上传文件。

素材三点菜单需检查所有主库、集合封面、单集行、搜索结果、继续学习、阅读书架和封面上传后的状态；最终浏览器验证还需覆盖浅色/深色、手机/桌面、非沉浸/沉浸。不因本预览有一个正确入口就声称真实 App 全部修复。

首页完整来源和自定义标签筛选、原有详细记录面板、编辑、造句、删除继续保留能力。缺可靠来源关联的旧词条保留真实来源文字和语义图标，不给它伪配节目封面。仅单词显示可靠音标；短语和句子无音标占位。
