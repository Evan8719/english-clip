# 已确认素材 UI、桌面书架与封面配置实现候选

基线 9781eca；用户确认桌面/手机版方案后要求继续。此前暂停的 MaterialSheet、ProgramCover、NavIcon 草稿在本轮续接。当前为本地实现候选，NAS 仍是 release-20261104-5e5c809-mobile-studio，未执行正式发布或资料迁移。

## 已实现

- 素材页改为主库页签、搜索、类别切换与封面网格；节目/课程进入后显示封面介绍、真实数量及单集列表。继续学习依据已有位置，不虚构完成率。
- 手机筛选采用原生模态 dialog 底部面板，等级、用途、排序用选项按钮；管理通过更多菜单进入，原有归属编辑继续使用。桌面为居中面板，支持 Escape、焦点约束和关闭。
- 阅读主库直接呈多列书架，窄屏为两列，保留原 Alice 插画与文字封面；选中书籍仍使用原 BookReader。目录、有限宽正文、手动选词、字号、阅读主题和沉浸模式保留，没有自动滚动选句弹窗。
- 右上角全局设置：手机固定顶栏使用齿轮，桌面单独保留；沉浸阅读内部也有设置入口。修复了 Aa 与设置、手机两个设置按钮重叠的问题。
- 节目、课程、书籍/素材的更多菜单支持更换封面与恢复默认。上传支持 PNG/JPEG/WebP，浏览器生成最大 240 像素缩略图和最大 960 像素详情 PNG，显示保存前预览。原图上限 20 MB / 2400 万像素，总请求上限 2.5 MB；服务端校验 PNG 文件头、尺寸和请求长度。未依赖外部图像服务。
- media/covers/index.json 仅存账号/目标及文件指纹，PNG 是独立文件；修改封面不重写素材索引。图片 URL 有时效签名，拒绝伪造、无签名、越权修改，CORS 只增加必要请求头，不放宽既有来源限制。图片恢复默认后保留旧文件，不自动删除原件或备份。
- 词卡和首页详情按 Entry.kind 控制音标：word 显示已有音标，phrase/sentence 不显示，发音操作保留。

## 保留边界

全局三皮肤仍为暂定方案，尚未完整接入设置；本子其他布局、开口练整体改版和闯关小游戏没有在此轮全部实现。此轮交付重点是已确认素材、书架、设置与封面功能。APK/iOS 工程尚未创建，也没有安装包；真实手机图片选择、语音和原生容器能力仍需实机验证。

自定义封面首次下载需联网；本机缓存图片不可用时回退默认封面，不影响词句和正文缓存。尚无裁剪工具、从 EPUB 自动提取全库封面或批量 AI 封面生成；上传只是单个素材/节目配置。旧版本封面文件未自动清理，后续空间管理另做。

正式发布前必须将 media-covers.mjs、material-taxonomy.mjs、media-progress.mjs 纳入完整程序包，将 covers/index.json 及 PNG 文件与 taxonomy/progress 数据纳入备份。当前未执行 NAS 停写、切换、正式账号验收或回退演练，不能按本记录声称已上线。
