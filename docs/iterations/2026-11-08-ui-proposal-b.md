## 保留约束

- 暖纸、清爽、夜读暂定，不在此轮重新改变皮肤选择。本对比图统一用浅色，集中评估页面结构。
- 单列词卡、粗体英文、明显卡片感、点按翻面继续保留；单词显示可靠音标，短语与句子不显示，但都可发音。
- 来源缩略图与真实出处对应；播客与书籍不混用封面。画面示例不是个人学习库新增内容。
- 素材沿用主库、类别、节目/课程、单集及用途标签结构，不退回文件树、文字层层展开。
- 无打卡压力、通知、体力或会员界面。闯关入口仅为后续功能构想，不能视为已完成。

## 与前版的可比较差异

| 方面 | 方案 B |
| --- | --- |
| 控件 | 搜索、标签、底栏保持平整，不给每个按钮加浮雕阴影；页面更轻 |
| 词卡 | 把厚度、投影集中用于词卡，凭卡面与底色、边缘、间距形成独立物件感 |
| 本子 | 搜索与筛选入口收敛，继续学习为小条；英文、音标、来源、标签分层排列 |
| 素材 | 按节目封面两列浏览，名称和集数在封面下；区别于管理列表和文件目录 |
| 复习 | 本轮先展示自由翻卡，单张卡居中、滑动切换与熟悉程度选择位置稳定 |
| 开口练 | 展示每日复述任务，一次聚焦一个动作；话筒是主操作，设置与说明退出主视线 |
| 导航 | 底栏贴合安全区，中心记录 + 稍突出；选中项仅图标与文字变蓝，不铺浅蓝块 |

图中位置、进度、题句是设计示意。正式实现仍需验证长文本、缺图、无音标、离线、键盘抬起、返回、屏幕阅读器和真机安全区等状态。用户确认此版或指定保留的部分后，才进入相应代码修改。
