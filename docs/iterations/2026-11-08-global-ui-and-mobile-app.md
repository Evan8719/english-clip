## 用户确认与执行边界

2026-11-08 用户认可素材视觉 Demo，并要求按同样逻辑检查其他页面，最终支持安卓和苹果安装。已确认的素材参考图保存在 [素材 Demo](../../design/demos/2026-11-08-materials-approved.png)。封面、缩略图、分区切换、单集列表、底部筛选是确认方向，不是已经上线的界面。

其他页面先出可视化 Demo，用户确认后再写对应 UI 代码。复习闯关仅为功能构想，未实现。此前刚开始的 MaterialSheet、ProgramCover、NavIcon 局部草稿仍保留但暂停，没有接入页面；不把它们当作成品，也不覆盖已验证的分类和进度候选。NAS 发布仍暂停。

已提供 [四屏全局视觉提案](../../design/demos/2026-11-08-global-ui-proposal.png)：本子、复习闯关、开口练、快速记录。此图尚待确认，不继承素材图的实现批准。图内词句、进度、对话均为示例；其中阅读条目的缩略图仍误用了节目封面，后续修稿与实现应按真实来源换成书籍封面，不能照着示意图误关联。

最新反馈：用户对四屏方向表示「基本可以」，首页需加强卡片感并增加常用皮肤；单词显示音标，短语不显示。已另提供 [首页皮肤修订稿](2026-11-08-home-card-skins.md)，等待对这轮修订的确认。此反馈不表示复习闯关等新功能已实现，也不解除 NAS 暂不发布的要求。

## 缩略图规则

节目用节目封面、电子书优先原书封面、视频优先已有缩略图；没有可用图片时使用一致的原创文字封面。可由用户上传、后续为故事生成封面；不把示意封面称为官方标识，不随意抓取版权未知图片。词句卡展示的是来源缩略图，不把封面当成词义。

正式实现需由 NAS 生成独立尺寸的缓存图，列表只载小图、详情再载大图，避免重新造成慢加载。原图不塞进 JSON 索引，不因更换封面更改素材 ID。当前还没有完整封面生成/提取后台，视觉稿不能视作已实现这些能力。

## 手机安装路线（核对官方文档）

当前 package.json 只有 React/Vite 网页和 Electron/macOS 打包，没有安卓或 iOS 工程，也没有已生成安装包。建议评估 Capacitor 复用现有界面与 NAS API；这是适配方案，不等于把网址加载进壳就验收完成。框架支持向现有 JavaScript 项目添加原生容器与平台桥接，见 [Capacitor 官方文档](https://capacitorjs.com/docs)。

- 安卓目标：可安装并升级的签名 APK；若以后进入应用商店，再准备相应发布产物。Android Studio 管理原生项目，APK 安装和更新需签名，发布密钥应由用户安全持有、不入 Git。依据：[Android 平台](https://capacitorjs.com/docs/android)、[Android 签名](https://developer.android.com/studio/publish/app-signing)。
- 苹果目标：iOS App，使用 Xcode 构建和签名。苹果不能安装 APK；测试可使用 TestFlight 或符合条件的已注册设备分发，具体按用户账号和设备条件选。签名与分发是单独步骤，不把随意发送 IPA 当成普遍可安装方案。依据：[iOS 平台](https://capacitorjs.com/docs/ios)、[Apple TestFlight](https://developer.apple.com/testflight/)、[注册设备分发](https://developer.apple.com/documentation/xcode/distributing-your-app-to-registered-devices)。
- 暂不安装依赖、创建平台工程、申请账号或购买签名服务；本轮只核对路线并记录需求。

## 原生适配必须验收的行为

1. 安装包内带前端资源，NAS 不可达时仍能打开已缓存词卡；NAS 继续负责跨设备资料和 AI 服务。原生构建明确 API 基址并验证平台来源，不解除所有来源/证书限制来凑通网络。
2. VoiceInput 当前依赖浏览器 SpeechRecognition，PracticeView 依赖 MediaRecorder，朗读依赖设备 speechSynthesis。原生容器是否支持需要真机验证；必要时使用平台能力接入录音、识别和朗读，保持现有失败恢复与隐私边界。不凭转写文字冒充发音评分。
3. 媒体播放、耳机中断、切后台、锁屏控制与回来恢复；网络断开后不能丢练习内容。后台音频能力当前不能宣称已完成。
4. 手机文件选择、共享导入、EPUB/字幕配对、下载与离线空间管理；文件路径不可直接等同 Windows 目录。目录选择有平台差异。
5. Android 系统返回、iOS 返回手势、底栏安全区、屏幕旋转及键盘抬起；记录的保存按钮必须可达。
6. 浏览器 IndexedDB 与原生容器存储不自动共享。NAS 已同步词条/资料可恢复，本机旧录音和未同步草稿需要迁移方案，不能以换客户端丢弃。
7. 初次安装、离线重开、登录恢复、升级覆盖、资料恢复和卸载前导出均用测试账号和真机验证。不能用网页冒烟或健康检查替代安装验收。

执行顺序：整套视觉 Demo→用户逐页确认→实现已确认 UI 与缩略图→手机能力适配→安卓签名安装测试→苹果签名安装测试→整体回归→再决定正式 NAS 与客户端发布。
