# 下一轮迭代计划

## 学习方法

用户提出新增「学习方法」板块。本轮先记录需求，下一轮与其他体验改动统一设计、实现和验收。

- 内容方向：汇总实用、精炼的英语学习理念与实操方法；每篇只解决一个具体问题。
- 呈现方式：短卡片说明“为什么有效”，紧接着给出可立即执行的步骤、示例和适用场景。
- 与现有功能结合：方法可指向记录、翻卡复习、听力素材、跟读和开口练的具体操作；避免孤立的长篇文章。
- 产品语气：安静、无打卡压力，不加入连续天数、通知或付费引导。
- 下一轮先做内容 brief 与信息架构，再确定导航位置、首批内容及手机端交互，随后统一改代码并发布。

验收重点：手机上容易找到；任一方法能在一分钟内读懂并开始练；内容有明确来源或可解释的依据；离线可读。
