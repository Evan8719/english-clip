## 行为

首页新增每日练习入口，开口练新增每日练习标签，保留原跟读和手动对话。用户选择 A1–C2 练习参考、5/10/20/30 分钟与生活场景。生成时只使用本账号少量生疏表达、已选素材在当前阅读/播放位置附近的短片段，以及最近三组每日练习的难度、复述和少量对话，不传整库，也不处理个人外链收藏。

练习包括 AI 简化阅读与简明英英释义、原句跟读、个人复述和情景对话；中文按需展开。原文与生成内容分开标注，可回到真实素材位置。跟读复用原录音页并有明确返回。AI 不宣称正式测评，不强制全英，不以固定理解率判断水平；下一组根据真实反馈调整句子复杂度和支持。

计划、完成步骤、复述、反思及完整文字对话保存在 data/media/daily-learning.json，按账号隔离，页面显示最近 30 组；旧记录不自动删除。缓存支持离线查看与草稿，联网后可手动保存同步。原跟读录音和旧手动练习仍在本机，未声称已跨设备迁移。新增学习方法卡与使用说明。
