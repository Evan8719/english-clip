英语剪贴本使用说明

记录真实遇到的表达，随时回来阅读、复习和开口练。词条优先保存在当前设备，NAS 用于同步和保存私人素材。

快速记录

• 点首页「记录新表达」或底栏中央「＋」。只填英文就能保存，出处、原句、理解和造句可稍后补。

• 记录弹窗支持滚动；保存按钮固定在底部。也可点麦克风输入英文，识别能力取决于设备和浏览器。

• 首页按最近记录在前显示。用搜索、出处分类和「调整」缩小范围；词句列表保持单列，兼容长句。

翻卡与复习

• 点卡片翻面看释义，再点翻回。复习页单词和音标居中，长句与背面内容左对齐。

• 左滑下一张，右滑上一张；上下滑仍用于滚动页面。两侧按钮也可用鼠标或键盘操作。

• 滑动只浏览，不改变熟悉程度。循环箭头表示「还生疏」，眼睛表示「有印象」，勾表示「能用了」；点选后保存并继续。

• 原句可展开查看；有素材来源的词条可以回到原文位置。

素材库

• 普通素材分听力、阅读和课程；用 A1–C2 参考等级筛选，可按名称/集数、最近添加或等级排序。每页 12 份。

• 「精选视频」是提前处理好的教材；「我的收集」是自己保存的外链，二者分开。

• 等级为编辑参考、来源参考或文本估算，不是官方能力测评。可按实际体验调整。

精选视频：打开即可学习

• 视频、字幕、逐词时间轴和中文学习对照已在电脑准备，保存在 NAS。按实际文件指纹匹配，观看时无需重新转写。

• 播放时绿色细框跟随当前词。点单词查义，再点书签记录；点麦克风用当前句开口练。

• 点「中」显示或隐藏中文对照；中文对照由英语剪贴本整理，来源署名保留在视频下方。

• 用前后箭头切句；展开「句子」可点选时间位置。播放器进度条也能拖动。

• 向下滑动浏览下一条，上一条会暂停；笔记和重点按需展开。

• 自动转写可能有误，词级时间缺失的区间保留句级显示，不用估算时间伪装逐词同步。

我的收集：轻量浏览外链

• 点素材库顶部链接图标，粘贴 YouTube、播客或网页地址，标题可自行填写。

• 同一链接不会重复保存。YouTube 可加载内嵌播放器，也可点外链图标打开原网页；其他网页从原站打开。

• 我的收集不下载、不自动转写、不进入精选或处理队列，也不保证带有字幕教材。

• 外部视频受原站、嵌入权限和网络影响；无法播放时可打开原网页。

阅读与沉浸模式

• 批量导入可选择 EPUB。素材库「阅读」里打开书籍，在目录中切换章节。

• 点「沉浸阅读」收起主导航；点「退出沉浸」返回，电脑也可按 Esc。

• Aa 可调字号、暖纸/明亮/夜间背景和章节。滚动时保存阅读位置，绿色细条表示本章位置。

• 拖选文字，或手机长按选词后，才出现查词、记录和复述操作；普通滑动不会自动挑句。

• 去开口练后，点顶部「返回刚才的素材 / 阅读位置」继续；切换其他页面也有继续素材入口。

• 已缓存的书籍可离线阅读；首次打开或跨设备使用需连接 NAS。

口语与 AI 对话

• 「跟读一句」可以听示范、录音并回听；「带词对话」可用麦克风识别英文，也可编辑文字。

• 勾选「说完自动发送」及「自动朗读 AI 回复」，可连续练习；AI 回复和自己的表达均能收藏。

• 文字反馈使用设置中选择的 DeepSeek 或 Gemini。麦克风需浏览器权限；不支持识别时可用系统键盘语音输入。

• 「跟读一句 / 带词对话」的旧练习对话和录音自动保存到当前设备，按账号隔离，目前不跨设备同步；下述「每日练习」的文字对话与学习状态保存在 NAS。

私人音视频如何转写

• 有同名 TXT/SRT/VTT 的音视频可一起批量导入，已有时间字幕可以点句定位。

• 没有文稿时可提交电脑队列，电脑的本地转写助手必须运行；电脑关闭则等待。手机可提交任务，不负责运算。

• NAS 负责存储和分发，本轮没有给 NAS 安装语音识别模型。

• 云端时间字幕是独立可选功能，需另配转写服务密钥；DeepSeek 文字密钥不能替代。我的收集不会调用此功能。

后续怎样补充精选

1. 从精选视频待选清单选一批，优先每批 3–5 条、不同等级与实用主题。

2. 在电脑取得原视频并保存出处，使用现有字幕工具批量转写，生成逐词时间轴。

3. 整理中文对照与重点，抽检开头、中间、结尾的声音、字幕、词框和译文。

4. 记录视频 ID、实际文件指纹、参考等级和资料版本，上传到 NAS 后检查播放与定位。

5. 检查合格才标为已上架。更新资料时保留词条、笔记和学习位置，并备份上一版。

当前补充工作由批处理和人工审核完成，App 内的「待选→处理→审核→上架」管理助手尚未实现。个人收集不会自动升级为精选。

数据和连接

• 在设置中登录 NAS 账号进行词条同步；手机与电脑需使用同一账号。素材保存在 NAS，练习历史当前在本机。

• 导出 JSON 可作为词条完整备份，Markdown 便于阅读。不要把清除浏览器数据当作退出登录，清除会影响本机未同步内容和练习记录。

• 移动网络的首次媒体加载受 NAS 上行与线路影响；已有文稿会压缩传输，媒体仅预加载必要信息。

• 程序升级与素材更新分开管理；源码进入 Git，私人素材、转写、账号和密钥不进入 Git。

NAS 的资料目录与备份

• 人工浏览资料使用应用目录下的 library：按视频、音频、电子书和系列分文件夹，文件名保留自然语言标题。旁边有原文、英文 SRT、中文 SRT（如有）、逐词 JSON 和资料说明。资料目录.csv 可用表格软件打开。

• 原来的长名字目录保留为兼容路径。两处原件通过同盘硬链接对应，没有再复制一套视频。改动硬链接文件的内容会影响同一原件；替换内容请作为新素材导入，整理名称不会改变 App 中的素材 ID。

• 目录整体整理会识别改过名称的同一文件，保留其关联。App 的笔记、词条来源和字幕不会依赖显示文件名。

• 程序包、学习数据备份、原始资料快照分开。日常备份词条、笔记、进度和索引，不反复把全部音视频压缩进程序备份。

• 原始资料单独维护版本或增量备份；同盘硬链接快照不会重复占用整份媒体的空间，但不能替代独立磁盘备份。

记录时按原句释义

• 登录并配置 AI 后，记录面板默认开启 AI 释义。英文、原句和来源会发送到当前选择的服务；补上原句通常更贴切。可关闭 AI，继续用本地词典和手动记录。

• 停止输入后自动释义；不必等 AI 返回，点保存即可先记下来，释义随后补上。中途离线的待处理记录会在重新联网后继续。

• 结果标注 AI 来源；不确定的新词会显示待确认。AI 也可能出错，不等于权威词典。

• 点「修改释义」保留自己的解释，自动结果不会覆盖；「按原句重释」可以主动重试。编辑旧词条默认保留原有释义。

选择 DeepSeek 或 Gemini

• 设置 → AI 释义与对话，选择服务标签。接口地址、模型 ID、回复方式都可修改；「恢复预设」只填入默认值，保存后生效。现有 DeepSeek 配置继续生效。

• Gemini 使用 Google AI Studio 创建的 API 密钥；Gemini 订阅不等同于外部 App 的 API 额度，API 用量单独管理。详见 Google 官方订阅说明。

• 密钥加密保存在 NAS，不回显到页面；不要把密钥填进笔记或分享截图。Gemini 没配置前无需切换，默认仍可使用 DeepSeek。

• 这里切换的是文字服务。手机语音输入依赖浏览器识别能力，回复朗读使用设备语音；音视频转写仍使用独立的本地队列或可选云端转写。

保存与测试连接

• 密钥按完整凭据保存，不限定旧前缀或旧长度，支持新版 Gemini 授权密钥。留空可保留已保存的密钥；不要附带引号、空格或换行。

• 点「保存设置」先加密保存；成功或错误提示就在当前区域。网络请求超过 12 秒会结束等待，保留输入；可点「重新读取状态」确认实际结果。

• 点「测试连接」才会发起一次简短模型请求。测试成功后点「设为当前服务」，释义、对话、素材重点都使用此服务的模型及地址。保存成功不等于密钥有调用额度或网络可达。

• 自定义地址需为公开 HTTPS、兼容 Chat Completions 的服务。更换地址须重新填写对应密钥，已有密钥不会自动发送到新地址。不支持把自定义地址用作 NAS 内网代理。

每日练习：把英文接到生活里

• 从首页「每日练习」，或开口练的同名标签进入。先选参考等级 A1–C2、5/10/20/30 分钟和生活场景；可以指定自己的书籍或音视频，也可按最近阅读/播放位置选取。

• 点「生成今日练习」时，AI 只读取本账号少量已同步词句、素材短片段、最近三组每日练习的难度反馈、复述与少量对话。不传整库、整本，不处理「我的收集」外链。

• 理解：先看 AI 简化短文和简明英英释义，抓大意；需要时展开中文帮助。AI 释义和改写并非权威词典或原文，原素材保留在下方供核对。

• 跟读：先听懂，再模仿节奏和重音；「录音跟读」复用原来的录音页，点「返回每日练习」继续。录音仍保存在当前设备。

• 复述：用自己会的英文说两三句，可语音输入；带着复述进入对话，AI 会参考它来反馈。语音识别不等于发音评分，不以识别文字推断口音准确度。

• 对话：围绕今天的表达聊自己的经历，可说完发送、朗读回复或收藏表达；当前 AI 服务负责短反馈与追问。结束后标记有点难/刚刚好/可以更难，保存一句反思，下次生成会参考。

• 参考等级由你选择；AI 根据词条熟悉程度和近期实际记录调整内容与支持，不冒充正式 CEFR 测评，也不强行禁止中文。

• 计划、完成步骤、复述、反思和完整文字对话保存在 NAS；同一账号可恢复。生成新一组会保留旧记录，页面列出最近 30 组，不删除旧记录。原来的手动练习历史不自动迁移。

• 已打开的计划有本机缓存，离线仍可查看、用设备朗读并写草稿；生成与 AI 对话需要联网。离线编辑后点保存会保留草稿，联网后再次点「保存练习」同步。不要在同步前清除浏览器数据。

• 不要求每天完成，也没有连续天数和提醒。生活里可只挑一句：散步时描述看到的东西，泡茶时说出动作，下班后复述一件小事，晚上与 AI 聊两分钟。

Gemini 连接与故障提示

• API 请求从 NAS 发出。电脑浏览器能访问 Google，不代表 NAS 可以；“fetch failed”可能发生在密钥校验之前。

• AI 设置可选「自动选择 / NAS 直接连接 / 通过 NAS 出网代理」。代理由 NAS 私有配置提供，不把代理地址或凭据回显到浏览器；默认只供 Gemini 自动使用，其他服务保持直连。

• 本轮启用的是经用户确认的电脑临时桥接：只接受 NAS 来源、只允许 Gemini 的 HTTPS CONNECT，原代理仍仅监听电脑本机，不改 NAS 的 SSH 转发禁令，不改防火墙，也不自动开机启动。电脑和原代理、桥接助手都须在线；电脑重启、地址变化或关闭助手后需重新连接。

• 需要 NAS 长期独立使用时，应另配置 NAS/路由器上的可用出网代理，或填写自己可信的兼容接口。不要把私人密钥发给未知中转服务。

• 点「读取可用模型」后可在模型 ID 中选择；模型目录不保证当前项目对每个型号都能调用，仍需点测试。旧型号可能不再对新用户开放。

• 「模型繁忙 / HTTP 503」是服务端暂时不可用；「额度为 0 / HTTP 429」需检查该 API 项目的用量和计费，Gemini 订阅与外部 API 额度分开管理。网络超时、DNS、代理关闭、证书、密钥权限与模型错误会分别说明，不会以读取列表成功冒充文字生成测试成功。

标签与素材分类

记录时可添加自定义标签，用逗号分隔；点已有标签添加，点 × 移除。首页可按标签筛选或搜索。

素材按类型、用途、节目或系列、等级筛选；列表先显示本账号缓存，再联网刷新。无结果时可清除筛选。首次加载和完整文稿仍需网络。

素材分层浏览

先选听力、阅读或课程，再进入节目和单集。已知资料自动归类；节目可设置默认用途，单集可覆盖并添加主题。编辑分组可改名，整理归属可修正单集。筛选收在「筛选与排序」，目录导入保留等级参考并匹配同目录文稿。
