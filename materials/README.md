# English Clip starter materials

This directory tracks the **source selection and the practice-page template**, not downloaded media.

- `starter-pack.sources.json` records the eight selected lessons, source URLs discovered from the source indexes, editorial prompts, and permission evidence.
- `starter-pack-index.html` is the offline-friendly practice page copied into a prepared pack.
- `npm run materials:starter` downloads the original audio/transcripts into ignored `work/`, validates every audio file, and emits hashes and a catalog.

The downloaded pack is intentionally excluded from Git. It contains third-party educational material and is deployed independently from the application release. Keep ELLLO attribution and original lesson links with every copy. The source pages state educational, non-commercial reuse; this project does not infer a specific Creative Commons version or commercial permission.
